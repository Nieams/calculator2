# Учебный проект
Данный проект представляет из себя простой калькулятор базовых арифметических операций, написанный на Python
Как использовать:
1) Запустите программу
2) В строке ввода введите первое число, нажмите enter
3) введите одну из операций в поле ввода: +,-,*,/, нажмите enter
4) введите второе число, нажмите enter
5) готово, вы увидите резльтат вычисления, соответствующий введенным данным
